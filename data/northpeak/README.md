# Northpeak Robotics document set (fictional)

Northpeak Robotics is a **fictional company** created for the EvalGate project. All people, products,
addresses, phone numbers (555 numbers) and email addresses (.example domains) are made up.
The documents were drafted with AI assistance and reviewed by the EvalGate team.

The set deliberately includes realistic "messiness": archived policy versions that conflict with current ones,
location- and role-specific rules, similar products with different specifications, error codes that mean
different things on different product families, announcements of future changes, historical support tickets
that contain outdated answers, and Confidential or Restricted documents the assistant must never reveal.

# Firmware Release Process

**Company:** Northpeak Robotics  
**Owner:** Engineering  
**Version:** 3.2  
**Effective date:** August 1, 2026  
**Classification:** Internal


## Code review
Changes to production robot firmware need **2 approvals** from engineers outside the author's team. Other code needs one approval.

## Testing before release
Every firmware release must pass the automated test suite and a **48 hours soak test** on real robots in the Boston lab before it reaches customers.

## Release days
Production firmware is released on **Tuesdays and Wednesdays only**. No production releases on Fridays or the day before a company holiday.

## Rollout
Releases go to 5% of customer robots first, then to all robots after 72 hours without new SEV1 or SEV2 incidents.

## Questions

Contact Engineering Operations at eng-ops@northpeak.example. This policy is reviewed once a year.

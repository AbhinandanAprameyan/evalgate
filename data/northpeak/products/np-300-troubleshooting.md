# NP-300 Hauler Troubleshooting Guide

**Company:** Northpeak Robotics  
**Owner:** Customer Support  
**Version:** 3.0  
**Effective date:** July 1, 2026  
**Classification:** Public


These error codes apply to **Hauler family robots** (NP-300, NP-350). Other Northpeak product families use the same codes with different meanings.

| Code | Meaning | What to do |
|---|---|---|
| E101 | Lift actuator overload | Remove the load, confirm it is within the rated payload, and run the lift self-test from the Fleet Console. |
| E102 | Load not centered on the deck | Re-position the load so it sits within the yellow deck markings. |
| E103 | Lost localization (cannot find its position on the map) | Drive the robot manually to a known map marker and select Relocalize in the Fleet Console. |
| E104 | Emergency stop engaged | Find the pressed emergency stop button, twist it clockwise to release it, then press Resume on the robot screen. |
| E105 | Hydraulic pressure low | Stop operation and contact Northpeak support; do not refill hydraulic fluid yourself. |

If a code appears three times in one shift, stop using the robot and contact Northpeak support at 1-800-555-0199.

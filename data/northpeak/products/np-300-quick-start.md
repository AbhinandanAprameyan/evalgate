# NP-300 Hauler Quick Start Card

**Company:** Northpeak Robotics  
**Owner:** Product Documentation  
**Version:** 1.0  
**Effective date:** July 1, 2026  
**Classification:** Public


1. Remove the red transport locks.
2. Place the dock against a wall with 1 meter of free space.
3. Hold the power button for 3 seconds.
4. Connect to Wi-Fi on the touchscreen.
5. Create a map in Mapping mode.
6. Start the first task from the Fleet Console.

Maximum payload: **300 kg**. Full charge: **4 hours**. Support: support@northpeak.example or 1-800-555-0199.

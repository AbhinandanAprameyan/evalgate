# NP-150 Courier Plus Troubleshooting Guide

**Company:** Northpeak Robotics  
**Owner:** Customer Support  
**Version:** 3.0  
**Effective date:** July 1, 2026  
**Classification:** Public


These error codes apply to **Courier family robots** (NP-100, NP-150). Other Northpeak product families use the same codes with different meanings.

| Code | Meaning | What to do |
|---|---|---|
| E101 | Battery temperature too high | Move the robot to a cooler area, let it rest for 30 minutes, and check that the battery vents are not blocked. |
| E102 | Lidar sensor obstructed | Clean the lidar window with a dry microfiber cloth and remove any tape, labels or debris near the sensor. |
| E103 | Lost localization (cannot find its position on the map) | Drive the robot manually to a known map marker and select Relocalize in the Fleet Console. |
| E104 | Wheel motor stall | Power the robot off, check the wheels for wrapped plastic or strapping, and restart. Contact support if the code returns. |
| E105 | Charging contact fault | Clean the charging contacts on both the robot and the dock with isopropyl alcohol. |

If a code appears three times in one shift, stop using the robot and contact Northpeak support at 1-800-555-0199.
